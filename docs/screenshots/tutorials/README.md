# Tutorial screenshots

Every lesson step as the coach-mark spotlight shows it, captured headless from the real app
at 1280×720 by `capture_every_step` in `crates/jvid-app/src/app/tutorial.rs`:

```sh
JVID_TUTORIAL_CAPTURE=/tmp/shots cargo test -p jvid-app --lib capture_every_step
```

`compare/` pairs each step of the old floating-card lessons (left) with the step that replaces it (right).
