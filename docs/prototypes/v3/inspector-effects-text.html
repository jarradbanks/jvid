Inspector, Effects and Text

Mockups for the three places that feel unfinished. The values and effects match the 24 Oct screenshot. Sliders, chevrons, diamonds, menus and tabs all work: drag Scale or Exposure, right-click a lit diamond, open Add Effect, switch the Effects tab to grid.

Thumbnails show the Program frame at the playhead with the effect or preset drawn over it. With nothing on the timeline they fall back to a bundled frame from the owner's own footage, which is the one used here.

Inspector

What's wrong now

  • Every row ends in the same reset and keyframe icons, about 250px from the value they act on. Twenty rows make forty identical icons, so the right edge reads as noise.
  • Values sit in a 64px column in a 440px panel. Most of the panel is empty, and it still scrolls.
  • Every section opens on launch and forgets that you closed it. Crop and Color, untouched, take as much room as the Transform you're editing.
  • Crop spends four rows on four zeros. LUT Mix shows while the LUT is None.
  • Effects sit at the bottom, under Audio. Up, Down and Remove are text buttons that appear or vanish with an effect's position, so they jump.
  • Add Effect is a dropdown pretending to be a button: its first item is "Add Effect" with a tick.
  • An animated row carries two diamonds, one to animate and one for a key at the playhead.

Row changes for both

  • One diamond per row. Click it to start animating. After that it shows whether there's a key at the playhead, and a click adds or removes one. Stop Animating moves to the diamond's right-click menu, beside easing.
  • Reset shows only when a value differs from its default. Its slot stays reserved, so nothing shifts, and the icon doubles as a "changed" marker. Section heads work the same way.
  • Keyframe arrows show only on animated rows, also in reserved slots.
  • Ranged values get a slider in the space after the field. Color grades, Rotation and Pan fill from the centre. The field still drags and types.
  • Crop is one row: L, T, R, B.
  • LUT Mix appears once a LUT is chosen. Try the LUT dropdown.
  • Effects are blocks: collapse, bypass, name, reset, and a menu with Move Up, Move Down, Reset and Remove. Drag a block's header to reorder.
  • Add Effect is a button that opens a menu with the same thumbnails as the Effects tab.
  • Speed uses the house field and checkboxes, not egui's stock DragValue.

Effects tab

What's wrong now

  • Hovering draws Apply on top of the description, so the line you're reading disappears under a button.
  • Every row says Bundled.
  • Descriptions show raw backticks (`amount`) and stop after one line.
  • Nothing shows what an effect looks like.

Proposed

  • A thumbnail of each effect drawn on the Program frame at the playhead, at 160×90. Redrawn when the playhead settles or the tab opens, never during playback. A broken shader shows the frame dimmed with a warning.
  • Apply (+) and More (⋯) sit in fixed columns on every row. + is greyed out with nothing selected. Hover changes only the fill.
  • Bundled and My Effects groups replace the per-row tag. Rows call out only Error and Disabled.
  • Parameter names in descriptions show as their labels, in Ink 2.
  • Grid view uses the same toggle as the Media tab.
  • Effect names show in Title Case ("Film Grain"), whatever the shader header says.

Text tab

What's wrong now

  • Three full-width buttons with no hint of what each one makes.
  • "Lower third" breaks the Title Case rule.

Proposed

  • Tiles that draw each preset on the Program frame with the real text renderer, at its true size and position, so you see how it sits on your own shot. Name and one line under each.
  • Same click and drag as now: click adds to the bin, drag goes onto the timeline.
  • True scale means a Caption reads small at tile size. It still shows where the text sits and how it's styled, which is the thing a button can't.
  • The frame is dimmed here so the mockup reads. The app should draw it as it is: white text on a bright shot looks the same in the tile as it will in the export.
