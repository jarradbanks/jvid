Export Queue and Export Dialog

Mockups for #261: the menu under the Export button that lists the render queue, and the Export dialog. Every frame is the app at its minimum window size, 960×600 (with_min_inner_size in app.rs), drawn at 1:1 in egui points.

Fields, strings and presets are the real ones from export/queue.rs, export/dialog.rs, jvid-core/src/preset.rs and i18n/en.toml. The dialog redesigns change layout only: the same fields, the same rules for what's enabled, the same buttons.

Recommendation

Queue menu: A, two-line rows in the menu. It is exactly the scope in #261 and the only one of the three where no row moves as jobs change state: four fixed columns, a second line that swaps content in place, and no job promoted out of the list. It stays a menu, so there's no new panel to dock and maintain. If people start queuing twenty highlights at a time, C's docked Render Queue can be added later on top of A's row component without changing it.

Dialog: A, three groups in one column. It maps one-to-one onto today's egui Grid (three Grids under section heads), so it's the cheapest to build with no behaviour change, and it still fits 960×600 with the footer pinned. It takes the best idea from B, Estimated Size next to the buttons, without B's 760px width. C's fold hides Target Size and Loudness, which are the reason many highlight exports open this dialog at all.

Decisions for the Owner

  • Preset names. The built-ins in preset.rs are in sentence case. The redesigns show them in Title Case ("Screen Recording (Sharp Text)", "ProRes Master", "Audio Only (WAV)"); that is a rename in preset.rs and [inspector] preset strings in en.toml, and user presets keep whatever name they were saved with.
  • Time left is new: elapsed time ÷ progress × (1 − progress), shown from 5% and smoothed; before that the row says "Estimating…". The job also needs its preset name and duration (and the file size once done) stored on Job, which today keeps only the path.
  • Progress is neutral, not blue. The bar is Ink on Border Strong. Blue stays for the primary action and selection (The One Blue Rule); Green only marks Done.
  • New strings for the redesign: Format, Output (section), Estimating…, {time} Left, No Exports Yet and its help line, Show Render Queue (C only), More Options (C only), "Output needs a file name". Everything else reuses [export].
