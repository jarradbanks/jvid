Centre Within the Content

Centre the whole group in the available panel body. Keep headers and transport controls outside that space. Scroll when a panel becomes too short.

Give One Useful Next Step

A short title and one sentence. Add an action when it helps: import media, start a transcript, or clear a search. No button for selecting a clip.

Keep the Editor Quiet

Use the panel's own surface and muted outline icons. Reserve blue for a useful primary action. Apply the shared layout to empty panels; keep errors and loading states distinct.
