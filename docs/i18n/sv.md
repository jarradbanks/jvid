# Glossary: Swedish (sv)

One Swedish word for each [glossary](glossary.md) term, used everywhere the term appears in the
`sv.toml` catalogs. Neither DaVinci Resolve nor Premiere Pro ships a Swedish interface, so the
terms follow Shotcut's Swedish translation where it reads naturally, and the words Swedish
editors use where it doesn't. Terms marked *unconfirmed* have no localized editor to check against.

## Conventions

- **Capitalization**: sentence case, as Swedish Windows and macOS do ("Nytt projekt",
  "Lägg till markör"); month abbreviations are lowercase.
- **Commands** use the imperative ("Spara", "Ta bort", "Klistra in"). The File menu is "Arkiv".
- **Messages addressed to the user** use "du".
- **Quotation marks** are ”…”.
- **Numbers and units**: a space before % and units ("{percent} %", "{value} s"); fps is "bild/s".

## Words kept apart

- Select is "markera" ("Markera allt", "Markerade klipp"), so Mark In/Out uses "sätt".
- A cut between clips is "snitt"; "klipp" is always the clip, "Klipp ut" the Edit command.
- Lossless export's Copy mode is "Strömkopia", so it never reads as Edit > Kopiera.
- Tint is "färgton" (as Lightroom); hue is "nyans".
- Lower third is "namnskylt", the Swedish broadcast term.
