# Glossary: Norwegian Bokmål (nb)

One Bokmål word for each [glossary](glossary.md) term, used everywhere the term appears in the
`nb.toml` catalogs. Neither DaVinci Resolve nor Premiere Pro ships a Norwegian interface, and
Kdenlive's and Shotcut's Norwegian catalogs are nearly empty, so jvid follows Apple's Norwegian
iMovie where it names the thing, and the words Norwegian editors use otherwise. Terms marked
*unconfirmed* have no shipped editor to check against and want a native editor's eye.

## Conventions

- **Capitalization**: sentence case for every label ("Nytt prosjekt", "Legg til markør").
- **Commands** use the imperative, as Windows and macOS do ("Lagre", "Åpne", "Avslutt");
  toggles name the thing ("Festing", "Koblet markering"). Questions to the user start
  "Vil du …?".
- **Quotation marks** are «…».
- **Dates** are day, then month in lower case ("24. okt.", "3. mars 2026").
- **Plurals**: Bokmål's rule is `one` (1) and `other`, as English.
- Blend modes follow Photoshop's Norwegian names as best recalled (Multipliser, Raster,
  Overlegg); *unconfirmed*.
