# Český glosář

The Czech translation of the [glossary](glossary.md): one word per term, used everywhere the
term appears in the `cs.toml` catalogs. See [Translating jvid](../translating.md).

Neither DaVinci Resolve nor Premiere Pro ships a Czech interface, so Czech-speaking editors
mostly work in English and borrow its words. The terms below follow the editors that are
localized into Czech, in this order: Adobe Premiere Elements (Adobe's own Czech Premiere
terminology), Kdenlive and Shotcut (both fully translated by Czech volunteers), then Microsoft
Clipchamp. Where they disagree, the note says which won and why. The Resolve and Premiere Pro
columns give the English word a Czech editor sees there.

## Conventions

- **Capitalization**: sentence case everywhere, labels included (Nový projekt, Vybrat vše), as
  Czech Windows, macOS, Kdenlive and Shotcut do. Panel names in running text keep their capital
  (panel Program).
- **Commands** (menus, buttons, keyboard actions, tooltips naming an action) use the infinitive:
  Uložit jako…, Exportovat snímek, Přidat značku. **Instructions** to the user use the imperative
  with vykání: Vyberte klip…, Přetáhněte sem média…. Status texts are nouns or past participles
  (Hotovo, Zrušeno).
- **Punctuation**: „Czech quotes“ (U+201E, U+201C), both in the bundled Inter subset.
- **Numbers and units**: a space before % and units ({percent} %, {value} MB); file sizes in kB,
  MB and GB; frame rates in fps. Shortcut notation (Ctrl+Shift+Z), codec and format names stay
  as written.
- **Dates**: day, then the abbreviated month as CLDR's Czech data writes it (12. led 2026).
- **Plurals**: `one` 1, `few` 2–4, `other` 0 and 5 and up, with the noun in the genitive plural
  and a singular neuter verb (5 klipů si zachová). Czech `many` is for fractions only, which never
  occur. Texts avoid the preposition before a number (z/ze changes with how the number is read).
