Korean DaVinci Resolve or Premiere Pro interface; where those two disagree, the note says which
one jvid follows. Use the one word below every time the term appears; see
[Translating jvid](../translating.md). Entries marked † are from memory of the localized
interfaces and not yet confirmed against a current build; a native Korean editor should check them.

## Conventions

- **Buttons and menu items** are noun phrases, as on Windows: 저장, 삭제, 새 프로젝트,
  다른 이름으로 저장…, 마커 추가, 인 포인트로 이동. No 하기/합니다 on a button.
- **Messages** use the polite 합니다 form (열 수 없습니다, 저장하시겠습니까?); hints and
  instructions end in -세요; short status lines end in a noun (내보내기 완료, 대기 중).
- **Particles after a placeholder** use the Windows notation 을(를), 이(가), 은(는), (으)로,
  와(과), since the final consonant isn't known; 의, 에, 에서 need none.
- **Punctuation**: ASCII `: ? ( )`; a name the user gave is quoted “{name}” only where English
  quotes it. The ellipsis … stays.
- **Numbers and units**: Korean counters attach to the number (1초, 3월, {count}개, {count}분 전);
  Latin units keep a space ({value} MB, {rate} fps). Korean has only the `other` plural form.
