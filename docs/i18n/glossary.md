# Glossary

The editing terms jvid's interface uses most, with what each means in jvid. Each language's
glossary (`docs/i18n/<code>.md`) gives one translation per term, matching the localized
DaVinci Resolve or Premiere Pro interface where one exists, and notes where they differ. Use
that one word everywhere the term appears; see [Translating jvid](../translating.md).

| Term | Meaning |
| --- | --- |
| Project | The saved file holding a timeline, its media references and its settings. |
| Media | The video, audio and image files a project imports. |
| Bin | The panel listing a project's imported media, titles and effects. |
| Clip | One piece of media placed on the timeline, with its own in and out points. |
| Track | One horizontal lane of the timeline; video tracks stack, audio tracks mix. |
| Timeline | The editing area where clips are arranged on tracks against time. |
| Playhead | The vertical line marking the current frame on the timeline. |
| Source | The viewer that plays a clip from the bin before it is edited in. |
| Program | The viewer that plays the edited timeline. |
| Viewer | Either picture panel, Source or Program. |
| Inspector | The panel showing the selected clip's properties for editing. |
| Effect | A filter applied to a clip's picture or sound, with adjustable parameters. |
| Transition | A blend between two neighbouring clips, such as a cross-dissolve. |
| Keyframe | A value pinned at one moment so a property can change over time. |
| Marker | A labelled point on the timeline or a clip, for notes and navigation. |
| In point | Where a clip or range starts. |
| Out point | Where a clip or range ends. |
| Range | The span of time between an in and an out point. |
| Trim | Shortening or lengthening a clip by moving its start or end. |
| Ripple | An edit that moves every later clip to close or open the gap it makes. |
| Roll | Moving the cut between two clips, trimming one as the other grows. |
| Slip | Shifting which part of the media a clip shows without moving the clip. |
| Split | Cutting one clip into two at the playhead. |
| Snapping | Clips and the playhead jumping to nearby edits and markers while dragging. |
| Link | Keeping a clip's video and audio selected and moved together. |
| Lock | Protecting a track so its clips can't be changed. |
| Mute | Silencing a track or clip without removing it. |
| Solo | Playing only the chosen tracks, silencing the rest. |
| Scrubbing | Dragging the playhead to hear and see the media as it passes. |
| Shuttle | Playing forward or backward at increasing speeds from the keyboard. |
| Timecode | A position or duration written as hours:minutes:seconds:frames. |
| Frame rate | How many frames play per second. |
| Resolution | The picture's width and height in pixels. |
| Aspect ratio | The picture's width relative to its height. |
| Proxy | A smaller copy of a media file that plays smoothly while editing. |
| Render | Computing the final frames of the edit. |
| Export | Writing the edited timeline out as a media file. |
| Render Queue | The list of exports waiting to run, running or finished. |
| Preset | A saved set of settings, such as an export format or text style. |
| Codec | The method that compresses a video or audio stream (its names stay as written). |
| Bitrate | How much data per second a compressed stream uses. |
| Title | A text clip made in jvid, such as a caption or lower third. |
| Subtitles | Timed text shown over the picture, imported or typed. |
| Waveform | The drawing of a clip's audio level over time. |
| Mixer | The panel setting each track's volume, pan and audio effects. |
| Voiceover | Narration recorded straight into a track while the timeline plays. |
| Undo / Redo | Stepping back through, and forward again through, recent edits. |
